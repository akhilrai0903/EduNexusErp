# 🎓 EduNexus ERP

EduNexus is an enterprise-grade School & College ERP and Management System built with a modern full-stack architecture.

## 🏗️ Architecture
- **Backend:** NestJS, TypeScript, TypeORM, PostgreSQL, Redis
- **Frontend:** Next.js 15 (App Router), React, Tailwind CSS
- **Infrastructure:** Docker Compose (PostgreSQL 17, Redis 7)

## 📌 Features in Development
- [x] Environment & Infrastructure Setup (Docker, PostgreSQL)
- [ ] Multi-tenant Architecture (Organizations & Schools)
- [ ] Authentication & Role-Based Access Control (RBAC)
- [ ] Student Information System (SIS)
- [ ] Academic Management & Timetables
- [ ] Examination & CBT (Computer-Based Testing)
- [ ] Finance & Billing System
